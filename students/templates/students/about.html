About This Project

The Student Management System is a full-stack web application built with Django, Bootstrap 5 and SQLite. It allows an institute to manage its student records with a complete set of Create, Read, Update and Delete (CRUD) operations.

Key Features
  • Add new students with a validated form, including a profile photo upload.
  • Browse all students in a responsive, sortable-looking table.
  • Search students instantly by name or roll number.
  • Edit any student's details, including replacing their photo.
  • Delete a student safely, with a confirmation step to prevent mistakes.
  • Manage everything from the Django admin panel as well.
Technology Stack
  • Backend: Python, Django
  • Database: SQLite (Django's default)
  • Frontend: HTML5, CSS3, Bootstrap 5, Bootstrap Icons
